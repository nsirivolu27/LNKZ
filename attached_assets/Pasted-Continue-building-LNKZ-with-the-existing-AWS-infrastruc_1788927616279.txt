The mobile application must provide this complete workflow:

1. Open the application and display a polished onboarding or connection screen.
2. Enter or load the LNKZ backend URL.
3. Enter an API key and store it with Expo SecureStore.
4. Test the connection using a real authenticated request.
5. Load real account statistics and recent conversations.
6. Browse and search the conversation library.
7. Open a conversation and read its messages.
8. Import a conversation using an existing supported import method.
9. Select messages or conversation content.
10. Build a context packet from the selected content.
11. Create a secure handoff with:
    - Name or recipient
    - Expiration
    - Access scope
    - Usage limit
12. Display the generated handoff link.
13. Copy or share the link using native mobile actions.
14. View active, expired, and revoked handoffs.
15. Revoke an active handoff.
16. View connector and connection status in Settings.
17. Disconnect safely and remove locally stored credentials.
