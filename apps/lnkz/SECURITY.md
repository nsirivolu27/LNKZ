# Security reports

Report suspected vulnerabilities privately through the repository's
[security advisory address](https://github.com/nsirivolu27/LNKZ/security/advisories/new).
Do not include credentials, live handoff links, or conversation bodies in a
public issue. Include a minimal reproduction with synthetic data, the commit
tested, deployment mode, impact, and suggested mitigation if known.

Security fixes target main. Tagged versions do not yet have a separate support
window. Until a fix is available, restrict network access to affected instances.

Operational controls belong in [DEPLOY.md](DEPLOY.md); the trust boundaries are
described in [ARCHITECTURE.md](ARCHITECTURE.md). Public disclosure should follow
coordination with the maintainer so operators have time to apply a fix.
